# Glosario del caso

> **Documento ficticio para el workshop de Kiro.**

| Término | Definición |
| --- | --- |
| **SKU** | Código único de un producto en una presentación específica, por ejemplo ANA-001 = Paracetamol 500 mg x 20 tabletas. |
| **Local** | Punto de venta físico. Código: marca (FY = Fybeca, SS = SanaSana), ciudad y número, por ejemplo SS-GYE-01. |
| **Reserva** | Unidades de un SKU apartadas en un local para un cliente que las retirará en persona. |
| **Retiro** | Entrega de una reserva al cliente en el local. |
| **Reserva vencida** | Reserva que no se retiró dentro del plazo y cuyo stock vuelve a estar disponible. |
| **Stock disponible** | Unidades de un SKU en un local que se pueden vender o reservar. |
| **Receta** | Orden médica necesaria para entregar ciertos medicamentos; la valida el químico farmacéutico. |
| **Cadena de frío** | Productos que deben conservarse entre 2 °C y 8 °C. |
| **Jefe de local** | Responsable de la operación diaria de un local. |
