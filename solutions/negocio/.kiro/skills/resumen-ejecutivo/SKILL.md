# Resumen ejecutivo para el comité

Escribe una sola página, en español, para personas que deciden y no leerán el detalle.

## Estructura obligatoria

1. **Contexto** (2–3 líneas): qué problema hay y a quién afecta, con una cifra si existe.
2. **Decisión que se pide**: una frase que se responda con sí o no.
3. **Impacto esperado**: hasta 3 viñetas con cifras o plazos.
4. **Riesgos**: hasta 3 viñetas, cada una con su mitigación.
5. **Próximos pasos**: quién hace qué y para cuándo.

## Reglas
- Sin jerga técnica: nada de endpoints, JSON ni nombres de archivos.
- Si falta un dato, escribe "Por confirmar" en lugar de inventarlo.
- Cierra con la fuente usada (por ejemplo, la spec del Lab 1).
